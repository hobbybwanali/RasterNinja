Release v1.0.0

This is the initial public release of RasterNinja.

Included in this release:
- dem_crop_plugin.py (main plugin code)
- metadata.txt (detailed metadata)
- README.md (project documentation)
- LICENSE (MIT)
- icon.png (plugin icon)
- icons/ (UI icons)
- dist/RasterNinja_v1.0.0.zip (distribution zip for plugin upload)

Notes about publishing to QGIS plugin repo:
- Use the ZIP in `dist/` when submitting.
- If you prefer to hide the email from public metadata, remove the `email=` line from metadata.txt before submission.
- Screenshots are included under `screenshots/` — replace them with real UI screenshots before submission.
